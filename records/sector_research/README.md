# 板块调研索引（Sector Research）

> **性质**：用户手动触发的板块深度调研，**非自动月触发模块**。每次由用户在对话中要求时执行，结果存此目录。
> **目的**：对候选池（110 只 / 48 板块）中代表性板块做产业链 + 景气 + 真实动量的深度理解，反哺动态选股系统的行业判断。
> **数据基准**：动量数据统一来自本地面板 `ashare_backtest/data/ashare_panel_close_em.csv`（东方财富后复权，金标准口径），与回测同源；产业逻辑参考当期公开研报/财报。

## 调研模板（后续手动触发时复用）

每份笔记含 7 节：
1. 板块定位与策略角色（候选池成分、系统里的作用）
2. 产业链结构（上游→中游→下游）
3. 近期真实动量（本地面板 13/26/52 周，标注数据周）
4. 景气与催化（产业逻辑 + 政策 + 当期事件）
5. 关键标的对比 / 谁是 alpha
6. 风险点
7. 对选股系统的含义 / 结论
