## 调研模板（后续手动触发时复用）

每份笔记含 7 节：
1. 板块定位与策略角色（候选池成分、系统里的作用）
2. 产业链结构（上游→中游→下游）
3. 近期真实动量（本地面板 13/26/52 周，标注数据周）
4. 景气与催化（产业逻辑 + 政策 + 当期事件）
5. 关键标的对比 / 谁是 alpha
6. 风险点
7. 对选股系统的含义 / 结论
