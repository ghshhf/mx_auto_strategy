# 旧篮 vs 新篮 · 逐周选币对比与倍数分解

> 生成：2026-08-13 | 10y 窗口 | 旧面板=1ace9eb(60币) vs 新面板=50币 | 受控 A/B/C/D 实验
> 脚本：`bt_pool_selection_diff.py`（逐周记录持仓对比）

## 一句话结论
**"两次选的币一模一样"不成立**：实测逐周选币只有 78~93% 一致，差异周全集中在减仓触发周；
**倍数少 1 万倍的主因不是选币变少，而是时机篮子变了**——被删的 PHB/HNT/METIS 等币历史上暴涨暴跌，
它们在 alt-RS 等权篮子里的价格历史塑造过减仓时机，删掉它们让 10y 倍数直接掉 46%（同逻辑、同可选中）。

## 受控实验（旧面板/新面板 × 旧逻辑/新逻辑，全 10y，档内配置一致）
| 运行 | 倍数 | CAGR | MDD | Sharpe |
|---|---:|---:|---:|---:|
| A 旧面板(60币)+旧逻辑 | 21,636x | 170.8% | −42.8% | 1.90 |
| B 新面板(50币)+旧逻辑 | 18,984x | 167.3% | −46.0% | 1.91 |
| C 新面板+新逻辑（现状） | 21,664x | 170.9% | −36.9% | 2.01 |
| D 旧面板+新逻辑 | 31,654x | 181.3% | −36.9% | 2.06 |

说明：
- 旧面板多出的 17 列（AXS/BEAM/BLZ/DYM/HNT/MANTRA/MATIC/METIS/PAS/PEAQ/PHB/RIO/RNDR/SECRET/SEI/STRK/TON）在当前 ca2 里**不可选**，只进 alt-RS 时机篮子 → A/B 与 C/D 的差别是**纯篮子效应**（选币宇宙完全相同）。
- B/C 同面板 → 纯逻辑漂移（08-11→08-13 的分阶段选币/fixed norm/php/ma 升级）。

## 逐周选币一致性（进攻持仓集合完全相同周数）
| 对比 | 一致周 | 比例 | 含义 |
|---|---:|---:|---|
| A vs B（纯篮子差，旧逻辑） | 402/512 | 78.5% | 每 5 周有 1 周选币不同 |
| B vs C（纯逻辑差） | 373/512 | 72.9% | 逻辑漂移也改选币 |
| C vs D（纯篮子差，新逻辑） | 478/512 | **93.4%** | 选币大体相同（6.6% 周不同） |

NAV 路径相关性：A vs B = 0.9989；B vs C = 0.9861。

## 关键结论：那 1 万倍差在哪
1. **选币不是一模一样，但也不是主因**。同逻辑下（C vs D）93.4% 周选币相同——但**不同的 6.6% 周（约 34 周）正是减仓触发周**：这些周是"满仓进攻 vs 转防御/现金"的抉择，少数几周抉择不同，10 年复利下就是倍数级差距（31,654 vs 21,664，+46%）。
2. **删掉的币不是"死币"**。PHB（2021 百倍）、HNT、METIS（ATH $323）、PEAQ 等在历史上暴涨暴跌——它们留在等权时机篮子里时，让 ALT/BTC 相对强度信号在关键周期段呈现不同形态 → 减仓时机更准。删掉它们 = 信号少了这些"剧烈参考点"。
3. **逻辑漂移反而是帮倒忙的反面**：B→C（升级逻辑）在相同新面板上把 18,984x 抬到 21,664x（+14%）且 MDD 从 −46% 压到 −37%——所以引擎升级是真的变好了；是**删币拖了后腿**。
4. **37,815x 的还原尝试**：1ace9eb 原版默认档复现 = 20,375x（Sharpe 2.00 与 README 一致，倍数对不上）；33009cd（分阶段选币）php=30 = 32,438x 最接近 → README 的 37,815x 是当时**调优扫描**的结果，不是任何 commit 的默认档。37k 时代的倍数本身就部分依赖旧篮子 boom-bust 历史（含后来被删的币）——**现在的 22k 是干净篮子的诚实下限，比 37k 更稳健**（MDD −36.9% vs 当年 −32~35%，但选币/篮子不再依赖已死币）。

## 对用户疑问的直接回答
- "每次选的币一模一样、没有减少" → **实测不是**：78~93% 周一致，差异周是减仓抉择周。
- "为什么少了 1 万倍" → **主要不是选币少了，是时机篮子变了**：删掉的 PHB/HNT/METIS 等币的历史涨跌曾参与塑造减仓时机（+46% 效应），选币层反而是次要通道（C vs D 选币 93.4% 一致但倍数差 46%）。
- 这也解释 STRK 删 −16.2%：单币在等权篮里的边界效应就能翻动均线交叉；整篮删掉 17 个 boom-bust 币自然更大。
