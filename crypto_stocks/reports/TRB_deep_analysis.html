一、项目底层逻辑与代币经济

1.1 它在解决什么问题

Tellor 是最老牌的去中心化预言机网络之一（2019 上线），核心定位是"数据的真理基准（benchmark for truth）"——它不聚合既有中心化 API，而是由无许可的 Reporter 网络自主生产数据，任何人质押 TRB 即可成为 Reporter，任何人可对可疑数据发起争议（Dispute），由 TRB 加权投票裁决并 slash 恶意方。这一"独立生产 + 争议仲裁"模型被 Tellor 视为比聚合式预言机更抗审查的结构性优势。

1.2 代币 TRB 的三重功能

  • 质押与报告：Reporter / Validator 须质押 TRB 作抵押，提交错误数据即被罚没（slash）——攻击成本 = 跨多轮质押并承担被罚没的 TRB。
  • 打赏 (Tipping)：用户以 TRB 打赏激励特定数据请求，价高者优先更新，形成市场化的优先级机制。
  • 治理与争议：TRB 持有者投票决定协议升级、参数调整与争议裁决；Tellor Layer 验证者上限 100，治理权重真实有效。

五、风险点（经三过滤重新定性）

对每条候选风险套用三问：①当前真实状态？②趋势方向？③是否 TRB 特异？剔除"已出清/行业共性/价基背离/赢家通吃/数据误读"类，余下真实风险。

市场常见叙事重新定性理由（三过滤）
"Chainlink 占 70% 份额，TRB 必死" 误判（赢家通吃谬误） 预言机市场正在细分：Chainlink=机构/默认层，Pyth=高频，RedStone=模块化，Tellor=定制/抗审查/争议感知利基。多赢共存，非零和。TRB 真风险是利基内执行/交付，而非 incumbent 体量。
"价格较 ATH −98%，基本面背离=最大风险" 误判（错杀论题） 价格/基本面长期背离是跨市场常态（Graham 投票机 vs 称重机）。若链上现实持续交付，背离=错杀信号；唯一真风险是"链上现实是否继续交付"。本例链上牵引难独立验证，故背离目前既不能证伪也不能确认为 bullish。
"无硬顶通胀 = 永久抛压" 部分误判 实测年通胀仅 ≈4.1%（cryptoinflation，2026-08），属低通胀；流通率 97%、绝对增发量小（日均 299 TRB ≈ $4,094）。稀释温和，非"永久抛压"。净中性偏负面，非致命。
"创始人/VC 解锁砸盘" 不适用 无 ICO、无预挖、无 VC 悬崖；团队仅取 10% 发行。MC/FDV 0.97 → 几乎无锁定待释放。已出清/不存在。
真实特有风险：Tellor Layer 未能转化为可持续预言机需求 核心风险 架构已证明，但独立链上 TVL/查询量难验证；若生产级集成增长不及开发投入，代币效用需求不足，价格锚将仅靠投机。这是唯一经三过滤保留的 TRB 特异风险。
