# 加密叠加层机制优化报告 (v6.23)

> 仅针对加密引擎。上一轮 walk-forward 揭示加密叠加层是「收益放大器 + 回撤放大器」(OOS 倍数 +22% t=5.4, 但 MDD 显著恶化 t=-5.98)。本工作验证**是否存在机制能消除回撤恶化**。

## 1. 方法

- 真实 OFF 基线(完全关闭叠加层)按窗口缓存, 不与 ON 混淆。
- 机制网格: 对称(tilt∈{0.3,0.5}) / 下行保护型(regime≥0 用 up, <0 用 down, down>up) / 纯保险型(up=0)。
- 指标: 3/5/10y ON/OFF 倍数比; 几何均值倍数比; 平均 MDD 变化(pp, >0=恶化)。
- 最优定义: 在 `平均MDD恶化 ≤ 2pp` 约束内最大化几何倍数比; 无满足则取 MDD 恶化最小。
- 对最优机制跑 walk-forward OOS(训练3y/测试1y 滚动, 2020-08 起), 输出几何倍数比 + paired t(倍数/MDD)。

## 4. 结论 (诚实)

1. **没有机制能消除回撤恶化。** 对称/下行保护/纯保险三类在所有窗口都显著放大 MDD(in-sample +4~+11pp; OOS t(MDD)=+6.4)。
2. **纯保险型(顺风不加仓)牺牲全部收益**: 10y 倍数比 < 1.0 (即负增益), 因加密增益主要来自「宏观宽松期顺趋势加仓」而非「逆风减仓躲崩盘」。
3. **这 4 个宏观周期是顺周期动量确认, 不是逆周期保险**: 它们只确认趋势方向, 但加密自身崩盘幅度(-80%)远超慢变量周期能预测的减仓幅度(下限砍半到0.5), 减仓根本躲不过崩盘。
4. **加密叠加层 = 收益/回撤 trade-off 旋钮, 非风控装置。** 推翻此前「崩盘保险」叙事。
5. **实践建议**: 想要更高收益且能承受更大回撤 -> 开启(tilt 0.3~0.5); 想要回撤控制 -> `cycle_overlay=False` 回到无叠加基线。引擎默认 `cycle_overlay=False`, 故默认不启用。
