# 周期叠加层参数优化报告 (v6.21)

> 免责声明：周期叠加层仅反映市场观点，非投资建议。回测含幸存者偏差与历史数据局限。

## 一、核心结论

- 当前默认 `cycle_tilt=0.5`（乘数∈[0.5,1.5]）**确实偏重**：在强趋势上行市里，
  composite_regime 多为轻微偏空/中性，大摆动会一路砍掉进攻仓的上行收益，
  而对回撤帮助有限。这正是 A股/美股被拖累、加密独善其身的原因。

- **推荐默认力度下调**：见下表各引擎最优 tilt。

  - **A股**：最优 tilt ≈ `0.0`
  - **美股**：最优 tilt ≈ `0.0`
  - **加密**：最优 tilt ≈ `0.5`
