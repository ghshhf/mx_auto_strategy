# 选币逻辑诊断与题材升级设计（crypto_options_bt + crypto_adoption_v2）

> 背景：用户质疑当前选币"只是看动量/最强"，可能误判/触判；要求加"行业/题材"层，
> 并"查看历史预判下一轮题材"。本文件先还原当前逻辑，再定位误判根因，最后给出
> **数据驱动（零前视）** 的题材升级方案与下一轮预判。
> 复现：`markets/crypto/_scratch_theme_leadership.py`

---

## 一、当前选币逻辑（是什么）

入口：`crypto_options_bt._build_target` → `ca2.offense_top_n(year, n=5, px, as_of=t)`。
每周在 `REGIME_ALLOC` 允许进攻时，从 **47 个进攻币**（12 赛道分类）选 **Top5**：

| 步 | 动作 | 来源 |
|---|---|---|
| 1 赛道相位权重 | 每赛道按 `PHASE_HISTORY`/`CRYPTO_THEMES` 的 S 曲线相位给乘子：`accelerating 1.35 / early 1.15 / saturating 0.65 / mature 0.80`，归一化为 `wt` | **手写、含 2026 回看标注** |
| 2 52 周动量 | 每币 52w 收益 − BTC 52w 收益 = 相对动量 `mom` | 价格数据 |
| 3 打分选股 | `score = max(mom,0)*wt + wt*0.3`，排序取 Top5 | — |

另有 6 个赛道指数（`compute_sector_indices`）：`L1/L2/DEFI/AI/WE3/RWA` + `BIGCAP`（BTC60/ETH30/SOL10）。
**但注意：这 6 个指数是"算出来好看"的，回测里 `offense_top_n` 根本没用它们的 RS——只用了手写相位权重。** 题材层是"死"的。

## 二、两大误判/触判根因（用户直觉完全正确）

### A. 前视手标（最致命，且是本项目的老毛病）
`PHASE_HISTORY` / `CRYPTO_THEMES` 是 **2026 年回看标注**。例如：
```
"AI+加密": [(2023,2024,"early"),(2025,2026,"accelerating")]   # as_of:"2026Q3"
"RWA":     [(2023,2024,"early"),(2025,2026,"accelerating")]
```
回测模拟 2024 时，系统"已知"AI/RWA 是加速甜区 → 给高权重。**这正是 A 股那边已"清算"过的
前视偏差**：手写 `PHASE_HISTORY` 让系统在 2019 就"知道"哪个行业会加速。crypto 这边原封不动又来一遍。
→ 题材"智能"在回测里是假的（答案被剧透）。

### B. 52 周动量买顶 + `max(mom,0)` 漏复苏（"触判"）
- 硬币涨到 +300% 52w 动量时往往已在局部顶 → 在顶部触发买入（触判）。
- `max(mom,0)` 把已回调的币直接归零 → 漏掉"已筑底、正在反转"的复苏领涨币。
- 52w 窗口在周期内反应迟钝，抓不住题材的 within-cycle 接力。

### 次要缺陷
- **静态 47 币池 + 静态赛道归属**：新爆款（本轮不在池中的）、死币滞留；幸存者偏差写死。
- **无周期内题材轮动**：题材领涨位随相位切换（DeFi 领 2021  euphoria，AI 领 2024 预热），年度静态权重抓不住。
- **选股不受减半相位门控**：周期层只缩放*敞口*，Top5 是哪 5 个与相位无关；高位本该退出高 beta 题材，现在不会。

## 四、升级设计：data_theme_lead（数据驱动、零前视）

### 1. 领涨题材检测（替换手写 PHASE_HISTORY）
每周 t（只用 ≤t 数据）：对 6 个赛道指数算 trailing RS（13w/26w）vs BIGCAP/BTC。
RS 最高的 1~2 个 = "当前领涨题材"。纯数据，可直接用于回测，无前视。

### 2. 选股倾斜（替换 `offense_top_n` 的 step1）
- 在进攻池内，**优先选"当前领涨题材"内的币**，按币自身 RS 排序；
- 保留 1~2 个席位给"次领涨题材"做分散（防单题材反转）；
- 动量项改用 **6~13w 中频相对动量 + 复苏过滤**（不强制 `max(mom,0)`，允许筑底反转币入围）。

### 3. 叠加减半相位门控（解决"高位不退高 beta"）
- accumulation/euphoria：领涨题材照常倾斜；
- 进入 crash/bear：不仅缩敞口，且**把 Top5 从高 beta 题材强制切回防御核**（BTC/ETH/OKB）+
  仅留 1 个领涨题材作卫星；
- 与现有 `alt_rs_gate` 协同：ALT/BTC 破 MA → 进一步缩进攻。

### 4. 历史轮动 → 下一轮预判（加密题材就那么多）
```
2017: ICO + 公链平台(ETH/NEO)           — "万物代币化"
2021: DeFi(UNI/AAVE) + NFT + meme + L1   — "链上乐高/高性能L1"
2024: AI(FET/RENDER/TAO) + RWA(ONDO) + 低费L1 + 模块化 — "AI×加密/现实上链"
```
**轮动定律：每一轮的爆发叙事 = 上一轮的"早期/边缘"题材成熟。**
（AI 在 2021 只是 early → 2024 成主线；DeFi 在 2017 只是"智能合约平台"→ 2021 成主线。）

**下一轮（≈2028 减半后）预判（数据+定律双支撑）：**
- 本轮（2024-26）已跑完的 AI/L2 在 2024 上行窗*已垫底* → **下一轮不会是同一批 AI 名字重演**，
  而是更细的子层/新早期题材。
- 高概率候选（当前仍"early/边缘"、未在 2024 领涨的）：
  1. **DePIN / AI 基建**（HNT/AKT/PEAQ）—— 承接"AI×加密"但换到物理基建层；
  2. **RWA 扩圈**（国债/股票/信用上链，监管落地后加速）；
  3. **模块化 / 意图 / 链抽象**（TIA/DYM/PAS）—— 本轮 early，下轮基建主线；
  4. **AI-Agent 自主经济**（本轮 AI 炒作子层，下轮分化出真现金流者）；
  5. **BTC L2 / 合规稳定币**（美国 GENIUS 法案后机构稳定币）；
  6. **wildcard：新一轮 memecoin 超级周期**（每轮必有，留口不预埋）。

## 五、落地步骤（严守项目 OOS 铁律：|t|≥2 才算真改进）

1. 在 `crypto_adoption_v2.py` 新增 `offense_top_n(..., mode='data_theme_lead')`：
   调用 `compute_sector_indices` 的 RS 检测，不再读 `PHASE_HISTORY`。
2. 新增 `THEME_NEXT_ROUND` 候选池（供"下一轮"情景压力测试，非默认押注）。
3. 周期门控：`_build_target` 在 crash/bear 把高 beta 题材席位收敛到防御核。
4. walk-forward 配对 t 检验（倍数 + MDD 双维度），仅当 |t|≥2 才把 `data_theme_lead` 设为默认。
5. 因切换移除了前视手标，**须复核 17000x 真值是否仍成立**（前视清零后数字应下降，属诚实修正）。

## 六、结论

当前选币 = "52 周动量 × **前视手标** 赛道相位，Top5"。两大误判：
**① 手标剧透答案（前视偏差，本项目老毛病）；② 动量买顶 + 漏复苏。**
数据驱动验证：**2024 真实领涨是低费 L1+RWA+WE3，AI/L2/DeFi 反而垫底**——手标方向性错配。
升级方向：用赛道指数 RS（零前视）检测领涨题材倾斜选股 + 减半相位门控退出高 beta +
历史轮动定律预判下一轮（DePIN/RWA扩圈/模块化/AI-Agent 最优先）。
全部改动须过 OOS 配对 t 检验，且因移除前视手标须复核 17000x 真值。
