# 多周期研究框架 (cycle_framework) — v6.19

> ⚠️ **免责声明（一／三处）**：本文档及 `cycles/` 模块输出的所有周期相位、合成 regime、未来价格情景，**仅为市场观点与研究假设，不构成任何投资建议**。周期分析用于理解宏观环境的结构性位置，不能预测资产价格。据此操作风险自担。

## 1. 这是什么

`cycles/` 是一个**跨市场（美股 / 加密 / A股）宏观周期叠加层**，把 12 个相互耦合的经济/市场周期归纳为统一的「风险顺风得分」(risk-on score ∈ [−1, +1]，+1 = 对风险资产最大顺风，−1 = 最大逆风)。它是研究引擎的**可选 (opt-in) 叠加信号**，沿用 A股回测已有的 `macro_overlay` 范式（前视防护 + 优雅降级），默认关闭、不污染基线回测。

设计三原则（与 `macro_fetch.py` 一致）：
1. **前视偏差防护**：每个周期序列写入 `available_date = 月份 + 发布滞后`，引擎只按 `available_date` 取数，从源头杜绝偷看未来。
2. **优雅降级**：任一序列抓不到 → 该周期相位归 0（中性），不报错、不改基线。
3. **额度守恒**：`tilt_multiplier` 输出 ∈ [0.5, 1.5]，不产生隐性杠杆。

## 4. 周期耦合关系

- **利率 ↔ 流动性 ↔ 美元**：美联储加息通常伴随缩表与美元走强（三维同向逆风）；降息/扩表则反向。当前利率松、流动性紧、美元软，三者出现罕见分化。
- **流动性 ↔ 风险资产（加密/美股）**：基础流动性是加密与长久期成长股的主要估值锚；流动性 −1.00 是加密端最关键的压制。
- **信贷 ↔ 情绪 ↔ 房地产**：信用利差走阔往往是情绪崩塌与房地产压力的前导；当前信用极宽松，是系统韧性的压舱石。
- **半导体库存 ↔ 科技AI创新**：AI 资本开支直接拉动高端半导体（HBM）需求，使库存周期在通用去库的同时出现结构性紧绷——两者当前共振偏顺风。
- **监管政策 ↔ 加密自身**：监管确定性提升（如美国稳定币立法）会直接改善加密自身周期的风险溢价；当前两者均微幅逆风但非系统性。

## 5. 方法论

- **相位计算**：取「截至查询日已可用的最新月度值」，对其过去窗口（默认 60 月，VIX 36 月）做 z 分数，乘各分量自身 `sign`（越高越顺风 = +1 / 越高越逆风 = −1）后裁剪到 [−1,1]。例：联邦利率由两个分量组成——`fed_funds`(sign −1) 与 `t10y2y`(sign +1，因倒挂=逆风已内含于其负 z)，各自归位后平均，避免相互抵消。
- **合成 regime**：12 周期按权重加权均值，裁剪到 [−1,1]。
- **前视防护**：所有量化序列的 `available_date = 月份 + 发布滞后`（取全组最大滞后 2 月，保守）；定性序列以 `assessment_date` 为可用日。引擎在 T 日只读取 `available_date ≤ T` 的行。
- **优雅降级**：文件缺失 / 列缺失 → 对应周期相位为 0，不影响其他周期与基线。已通过 `tests/test_cycles.py`（8 项，含前视不可见、相位有界、缺失降级、额度守恒）验证。

## 6. 如何接入三市场引擎（opt-in）

模块与现有 `macro_overlay` 同构，可作为第四个市场的统一叠加层：

```python
from cycles import load_cycles, cycle_phase_at, composite_regime, tilt_multiplier

st = load_cycles("cycles/data/cycles_raw.csv", "cycles/data/cycles_qualitative_seed.csv")
regime = composite_regime(st, query_date)          # ∈ [-1, 1]
mult   = tilt_multiplier(regime, tilt=0.5)          # ∈ [0.5, 1.5]
# 将 mult 乘到进攻仓位比例，等价于 macro_overlay 的 macro_tilt 语义
```

默认 `tilt=0.5` 即「regime 每偏离中性 1 个单位，进攻仓位在 [0.5, 1.5] 倍区间调整」。接入前须确认 `cycles/data/cycles_raw.csv` 已最新（`python -m cycles.fetch` 重新抓取），否则退化为中性。
