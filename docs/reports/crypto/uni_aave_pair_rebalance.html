七、平均每年增加多少筹码 / 还能拉多少年

⚠️ 本节只用筹码口径，不使用"超额收益"。超额是净值除法，会被两币价格涨跌幅度、起点价选择、 死拿口径的起点歧义共同污染（同币同窗口换一个起点，超额可差数个百分点）， 无法分辨"机器效率"与"标的运气"。筹码（币量倍数）不含价格，是唯一干净的口径。

为什么 UNI 和 AAVE 的增速差这么多？拆成两块（只用各币价格倍数，不引入净值）：
log 筹码增速_i = 组合筹码年化 + ½ × (log 价格倍数_另一边 − log 价格倍数_i) ÷ T
  • 组合筹码年化 = +6.79%/年 —— 这是波动收割，可重复的机器产出，两边都有
  • 搬运项（零和）：窗口内 UNI 涨得少、AAVE 涨得多，再平衡就把 AAVE 的涨幅搬成 UNI 的币量 → UNI +3.66% ／ AAVE -3.53%（两者相加 ≈ 0）
所以 UNI 的 +11.31%/年 里，只有 6.79pp 是真增量，其余是搬运 —— 搬运部分意味着"用 AAVE 的涨幅换了 UNI 的币量"，不是凭空多出来的财富。
评估这套机制请盯组合筹码（+6.79%/年），不要盯单币筹码倍数。

7.4 "还能拉多少年"取决于波动率，不是时间

组合筹码年化的来源只有两个：波动与相关性，与两币涨跌方向无关。 等波动近似下 组合筹码年化 = ¼ (1 − ρ) · σ²。 它没有到期日，只有衰减路径——只要波动还在，搬运就在发生。

结论：每年几个点、能拉多少年
  • 每年：组合层面 +6.79%（样本下界 +2.12%、 中位 +5.39%）。单币层面 UNI +11.31%、 AAVE +2.45%——但"谁多谁少"由价格相对强弱决定，会反转（近 1 年已反）。 真正可重复的只有组合那一项。
  • 多少年：数学上无期限。组合筹码年化归零需要相关系数达到 ρ* = (k²+1)/(2k)（k = 两币波动之比）。实测 k = 0.9850 → ρ* = 1.0001， 而 ρ 最大只到 1 —— 不可达。只要两币波动不完全相同，收割恒为正。 样本内验证：滚动 2 年窗口为负的比例 0.0%。
  • 实际约束是"变薄"而非"到期"：σ 从 110% 掉到 60%，年化从 +8.3% 降到 +2.5%； 掉到 30% 只剩 +0.6%（机器还在跑，但没肉）。要盯的是 σ 与 ρ，不是年份。
  • 真正会终结的是三种情形：① ρ → 0.9（两币完全同涨同跌，没有强弱差可搬运，年化被砍到当前水平的约 36%）； ② σ 坍塌（币成熟到 30% 以下）；③ 单币归零 / 被踢出池—— 这是唯一让筹码口径彻底失效的情形：币量可以堆到很高，但价格归零，筹码不值钱。 所以池子准入（熊市幸存币、不掉队）比调仓参数重要得多。
  • 翻倍时间：按组合筹码 +6.79%/年，翻倍约 10.6 年、 十倍约 35.1 年。

八、口径与数据说明

  • 筹码口径（根本答案）：units_mult = 期末币量 / 死拿币量，死拿 = 1.000，<1 即掉队。 这是再平衡真正做的事，不受价格与起点价污染。
  • 美元口径：nav = Σ w_c · R_c · Pnorm_c，回答"赚几倍"。它与筹码倍数不可互换。
  • 超额：再平衡净值 ÷ 同币同窗口等权死拿净值 − 1，衡量"机器效率"，与标的涨跌无关。
  • 成本：主口径单边 10bp，按当期成交额扣减；表中另给 0 / 30bp。
  • 窗口：两币公共窗口取较晚的起始日（2020-10-09，AAVE 上市），死亡期不参与。
  • 数据：weekly_adjclose_crypto50_10y.csv（周频后复权，27 币）。 面板末格日期为 2026-09-11，其承载价格为最新交易周（含最新收盘）。
  • ⚠️ 已知数据特征：该面板的日期标签由交易所周K（周一开盘）经 (weekday-4)%7 映射而来， 实际承载的价格对应标签日 +9 天的收盘（即标签比价格早约 7 个交易日）。 该偏移对所有币一致，不影响收益序列与筹码倍数，但会使"面板末日"看起来比真实交易日更早。
