> 生成时间：2026-07-25（基于 `US_backtest_report.md` 的弱点诊断做针对性优化）
> 数据窗口：2016-08-01 ~ 2026-07-20（约 9.97 年），起步 10000，现金比例**恒定 16%**，再平衡只在防御↔进攻间搬（不取钱）

## 一、针对四个弱点的优化动作

| 用户指令 | 优化做法 | 改动 |
|---|---|---|
| 进攻仓位升级 | 踢掉最弱的 **CRL（2.64x）**，换 **AMD（78.96x）** | OFF4: TSLA / NVDA / AMAT / **AMD** |
| 防御仓位优化 | 踢掉亏钱的 **STZ（0.93x）**、平庸的 **PEP（1.71x）/ CVX（2.96x）**，换真·低波动红利成长 **KO / PG / ABBV** | DEF6: JPM / UNP / NEE / **KO / PG / ABBV** |
| 进攻比例上升 | 三档进攻权重大幅上调（现金恒 16%） | 弱/平/强 = 防御 **56/44/34%**，进攻 **28/40/50%**（原 60/54/44 与 24/30/40） |
| 回测控制拉大 | 再平衡由"周频强制"改为"漂移阈值"控制（只在某篮偏离目标超阈值才搬回） | 阈值 TOL 扫描 0~0.70 |

## 四、三个关键发现（重要）

### 4.1 主升力来自"进攻升级 + 比例上升"，不是控制拉大

把原框架（6.81x）逐项拆解：
- 仅**换篮 + 提进攻比例 + 严再平衡**（V3a）= **13.63x** → 直接翻倍。
- 这说明真正起作用的是**选了更炸的进攻标的（AMD 替代 CRL）+ 把进攻仓位从最高 40% 提到 50%**。

### 4.2 "回测控制拉大"反直觉：严格周频再平衡反而最优

按你的要求把再平衡阈值放宽（TOL 扫描），结果：

![再平衡阈值扫描](mx_us_backtest/charts/opt_tol_sweep.png)

| 再平衡阈值 TOL | 10年倍数 | 最大回撤 |
|---|---|---|
| **0.00（严格周频）** | **13.63x** | **-28.3%** |
| 0.10 | 13.17x | -29.0% |
| 0.20 | 12.44x | -28.9% |
| 0.30 | 7.82x | -38.9% |
| 0.40 | 20.24x | **-45.3%** |
| 0.50 | 13.27x | -45.3% |
| 0.70 | 20.84x | -45.3% |

- **中等放宽（0.10~0.20）反而略降**：因为对 NVDA/AMD 这种高波动进攻标的，周频再平衡本质是在篮内"卖高买低"做波动收割，放宽后少了这道增益。
- **只有放到极端（0.40+）才冲到 ~20x**，但代价是**回撤翻倍到 -45%**（几乎不搬，2022 暴跌硬扛）。
- 所以"让进攻多跑"的直觉只在**你愿意承受翻倍回撤**时才兑现；中等放宽纯属吃亏。

> 建议：**保留严格周频再平衡（V3a）**。若你坚持要"宽控制"，V3b（TOL=0.15，13.01x）是代价最小的折中；想要 ~20x 就得接受 -45% 回撤（TOL≥0.4）。

### 4.3 死叉层在进攻加重版里严重拖累，应弃用

V3c（宽控制 + 死叉 th=4）= **5.47x**，比不开死叉的 V3b（13.01x）惨跌 58%。原因：死叉强制把 NVDA/AMD 这类进攻仓砍进防御，正好砍在 2020/2022/2025 每次急跌后、错失最猛的反弹。仓库里死叉"压回撤"的有效性完全建立在 A 股防御篮的低 beta 上，在美股进攻加重策略里纯属砍赢家。

> 建议：美股优化版**关闭死叉层**。

## 六、⚠️ 重要警示：这是后视镜优化（过拟合风险）

本次"升级"本质上**用了 2016-2026 的已知答案选股**：AMD 78.96x、NVDA 144.97x 是因为我们已经知道它们涨最猛才选的。实盘你**无法预知**下一个十年谁是最猛的。真实风险：

1. **幸存者偏差**：选的是过去赢家，未来未必。AMD/NVDA 的高倍数不可线性外推。
2. **集中度高**：进攻 50% 押在 4 只高 beta 科技股，单票黑天鹅（反垄断、AI 资本开支退潮）回撤会远超 -28%。
3. **回撤 -28%~-45%**：远超 A 股原版的 -20.9%，需确认你能睡得着。
4. **未计成本/税**：周频再平衡 + 高换手，美股短期资本利得税和摩擦会显著侵蚀。
5. **样本区间依赖**：2016-2026 是美股长牛+AI 超级周期，结论不可外推。

> 若要做成**可实盘的前向策略**，应把"进攻升级"改成**规则化主题倾斜**（如"AI/半导体/清洁能源高 beta 成长"定性池，每季度按动量轮动），而非固定押注 NVDA/AMD 这四个已知赢家。

## 八、一句话总结

> 按四个弱点针对性优化后，美股版从 **6.8x → 13.6x（年化 30%）**，已逼近 A 股 16.8x。主升力是**进攻换 AMD + 进攻比例提到 50%**；**防御优化**小幅补强；但**"拉大控制"反而略亏**（严格周频再平衡最优），**死叉层在进攻加重版严重拖累应关掉**。代价是回撤升到 -28%（极端宽控制会到 -45%），且这是后视镜选股，实盘不可直接外推。
