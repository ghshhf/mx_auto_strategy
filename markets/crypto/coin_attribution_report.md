# 逐币 Leave-One-Out 归因报告

> 生成时间: 2026-08-13  |  方法: 逐个删除进攻币, 跑三窗口回测
> Δ收益% = (删后倍数 / 基线倍数 - 1) × 100
> 正值 = 删了反而涨 → 该币拖累收益 (删除候选)
> 负值 = 删了跌 → 该币有正贡献 (保留)
