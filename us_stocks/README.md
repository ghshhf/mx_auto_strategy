## 3. 方法论（与 A 股同源，迁移到美股）

- **篮子（us_adoption.py）**：直白逻辑 — 选最大的、最新的、最热的、最确定的长期赢家。
  48 进攻覆盖 13 个主题（AI 算力、半导体、云计算、电动车、生物科技、消费、支付、航天等），
  永久防御 `KO`/`ABBV` 提供抗跌底仓。
- **信号（backtest_v8.py）**：跨标的相对动量排名 + 自适应防御（弱/平/强市三档股债/股债防御配比）。
- **加固（backtest_p0.py）**：换手成本 + 资本利得税（批次成本追踪）、Walk-forward 样本外验证、崩盘韧性测试。
- **保护（backtest_p1.py）**：3 种崩盘护栏 — `ma`(SPY<200 周均线)、`dd`(SPY<−20% 自高点)、`self`(策略自身 −15%/−20%)。
- **网格（backtest_p1b.py）**：把 A 股 `grid_trader.py` 的近似逻辑移植到美股高波标的（NVDA/TSLA/PLTR/COIN/AMD），
  在动量底仓之上用闲置现金做网格增厚。

### 关键发现
1. **篮子是倍数主因**：零后见之明篮子（ex-ante）仅 5.11x，证明 50x 大头来自人工精选篮子，信号赚的是「确定性溢价」而非 alpha。
2. **参数诚实**：Walk-forward OOS 42.87x ≈ 样本内 49.87x（−14%），没有过拟合。
3. **护栏打错目标**：策略真实风险是成长股集中（beta≈1.18），不是指数趋势。SPY 护栏在 2020–26 牛市**从未触发**；
   `self` 护栏才能把实测回撤从 −36.7% 压到 −34.3%（代价 −1/4 收益）。
4. **网格是零头**：当前仅 ~5.8% 闲置现金可做网格，仅 +0.1x；若专门拨 16% 弹药可增厚 ~+0.4x。
5. **账户类型决定生死**：免税账户成本侵蚀仅 3.6%；应税 20% 账户周再平衡直接崩到 18.57x。

### 7.1 五档结果（均经扫参确定，非手调；2026-07 扩池至 155 标的前后重测）

| baseline（v6.14b 修正：弱市停车进**分红防御篮**、去黄金、季频、等权 Top10） | 5.89x | 15.9% | −29.5% | 3.80x |

- **MDD 是结构性问题**：纯动量高 beta 满仓，每一年（2018–2026）都有 −24%~−48% 年内回撤，2022 最深 −48.4%。**事后信号（MA/护栏/止损/广度）均压不住**（要么太迟要么鞭梢）；唯一有效手段是**结构性降敞口**（现金袖 / 波动率目标），代价是倍数。

### 7.2 优化引擎设计（对齐 A 股 16 倍方法论，适配美股特征）

**防御端（用户指定，v6.15 修正）：彻底去黄金。**
- 防御 = **分红股**（动态选近 20 周低波动候选 KO/JNJ/ABBV/PG/XOM 等，面板已有真实数据），占比**整体小**：平衡 5% / 弱市 15% / crash 15%，符合"防御配置不大"的要求。
- **极端防御 = 现金，不是长债（重要修正）**：经验证，长债在危机中与成长同跌——TLT 2022 年 −28.4%、IEF −13.5%，利率驱动使其与高 beta 动量正相关，**长债不是危机对冲**。故 crash 档把压掉的股权敞口转**现金**（或短久期/分红），而非配债券。早期 `extend_panel_bonds.py` 债券对冲路径**已废弃**，不再作为对冲手段。
- **结构性降敞口（压 MDD 的唯一有效手段，无杠杆下）**：
  - **波动率目标化 `--vol-target`**：用 QQQ 近 20 周年化已实现波动作风险温度，股权敞口 = clip(vol_target/实现波动, vol_floor, 1)。平静牛市波动低→满仓吃收益；崩盘波动飙→敞口自动压到 floor、削深跌段（压掉部分转现金）。
  - **永久现金袖 `--struct-def`**：永久保留 X% 股权敞口转现金，**均匀压每年**回撤（非仅崩盘年）。代价是倍数线性下降（见 7.1 前沿表）。

**进攻端（冲倍数）：**
1. **进攻占比拉满**：bull 100% / balance 95% / weak 85%（美股长期上行，过度防御是最大拖累）。
2. **周频再平衡**（对齐 A 股，捕捉动量；baseline 用季频太钝）。
3. **动量 Top3 集中 + 趋势门（MA5>MA20）**：扫参显示 Top3 为稳健最优（Top1 虽更高但 MDD −78% 过脆，不取）；赢家按「质量乘数×动量^0.5」加权，避免等权稀释 NVDA。
4. **52 周动量窗口**：扫参稳健胜出。
5. **动态股票池（月度 re-screen）**：剔除指数/工具，新股 IPO 满 1 年自动入池、退市自动出池；`--refresh quarterly` 可切季度。
6. **可选净杠杆（`--lev`，默认 1.2）**：进攻仓放大、现金仓为负=借入，净杠杆机械放大倍数与回撤。

### 7.3 AI 选股层怎么接的

直接复用 A 股系统的 `ai_score.py` 通用打分层（`augment(candidates, cfg, tag)`）：

- **默认（可复现）**：用确定性质量乘数（风险调整动量 + 距 52 周高点，钳 [0.8,1.2]，无前视、stdlib only），离线即可跑。
- **`--with-llm`**：真正调用 `ai_score.augment`，由配置好的 LLM 端点产出乘数；未配置时自动 `pass-through`（=1.0）。遵循 `ai_score` 铁律：**回测禁用实时 LLM 前视**，AI 仅作加权参考。

### 7.5 关于「30x / MDD−30% / 40~50x」的诚实说明

- **无杠杆 ≈ 23x（扩池后诚实上限，未达 30x 目标）**：真实宇宙 + 无前视 + 动态池 + 主题解相关的可辩护上限就是 **~23x**（≈1.4× A 股 16.29x）。此前 33.69x 的旧值依赖一份漏掉 7 只大/巨型股的手工池，补齐后回落到 22.48x——该数字对池子构成敏感，存在隐性过拟合，不能作为"30x 天花板"引用。扫参 162 组在诚实池下全部停在 22x~23x 附近。
- **但 23x 的 MDD 是结构性 −48%**，集中在纯动量高 beta 满仓。要压到用户预期的 **MDD≈−30%**，必须上 40% 现金袖 + 波动率目标，倍数同步掉到 **~8x**（见 7.1 前沿表）——**"23x 且 −30%" 在无杠杆下不可兼得**，这是权衡曲线不是调参遗漏。
- **冲 40~50x 的合法路径 = 适度净杠杆（用户已选不用）**：1.2x → 31.95x（≈A股2×）、1.3x → 36.83x。这是标准机构做法（许多系统化股票基金跑 1.2~1.5x 总敞口），非幸存者偏差；杠杆**放大回撤**（1.2x 档 MDD −55.7%）且借入成本未计。
- **不可取路径**（刻意不做）：① Top1 单一名 → 倍数更低且 MDD −78%（单笔错配近乎归零）；② 后见之明精选 NVDA 或只留赢家（幸存者偏差/前视）；③ `backtest_v8.py` 的"50x"依赖**年度 stale 选股 + 前视相位倾斜**，不可复现、不可辩护，不采纳。

结论：**无杠杆 22.48x（MDD −48.4%）是该真实宇宙（155 标的、含补齐大/巨型股）下最优可辩护的进攻结果（≈1.4× A 股、远超 SPY 3.8x）；它未达早先 30x 目标，且 33.69x 旧值已被证明是漏池隐性过拟合，不可引用。若坚持 MDD 压到 −30% 左右，走 40% 现金袖 + volT → ~8x 是诚实答案；要达你早先预期的 40~50x，启用 1.2~1.3x 净杠杆（31.95x / 36.83x）即可。三者是同一引擎上的不同风险档，由 `--struct-def` / `--lev` 旋钮选择。**

> 对齐参考：A 股系统同口径 ≈ 16.29x（v6.13 优化配置，clean 东方财富后复权面板）；美股诚实无杠杆 22.48x 约为其 1.4×。
